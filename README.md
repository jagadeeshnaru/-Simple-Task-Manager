# -Simple-Task-Manager
A clean and minimal task management application designed to help you stay organized and productive. With an intuitive interface, you can easily add, track, and clear tasks while monitoring your daily progress.
✨ Features
📝 Add tasks with priority levels and due dates

✅ Mark tasks as Active or Done

🔄 Filter tasks by status (All / Active / Done)

🗑️ Clear completed tasks with one click

📊 Progress indicator to visualize daily completion

📅 Date-based task tracking

🚀 Tech Stack
Frontend: HTML, CSS, JavaScript


🎯 Use Case
Perfect for students, professionals, or anyone who wants a lightweight and distraction-free way to manage their daily tasks.
